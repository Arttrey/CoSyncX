# Движки передачи CoSyncX

CoSyncX поддерживает два режима: отдельный управляемый экземпляр Syncthing с
собственным каталогом и подключение к уже работающему экземпляру. Переключение
не меняет форматы снимков и не означает разрешение записывать в состояние Codex.

Реализованный экспериментальный запуск:

1. `python tools/build_portable.py --output <новый-каталог>` собирает на
   текущей ОС автономный файл с Syncthing 2.1.7. Необходимы Python,
   зависимости проекта и PyInstaller 6.15+; официальный архив проверяется по
   закреплённому SHA-256. Можно указать `--archive <скачанный-архив>`.
   В каталоге результата находятся программа и лицензии CoSyncX и Syncthing.
2. `cosyncx engine prepare-managed --home <новый-каталог> --gui-port <порт>`
   создаёт отдельный профиль; `cosyncx engine run-managed --home <каталог>`
   запускает его в текущем терминале. Команды из исходников принимают явный
   `--binary <проверенный-файл>` вместо включённого в сборку бинарника.
   Для соединений с другими устройствами пользователь может явно указать
   `--listen tcp://0.0.0.0:<порт>`; без него доступен только localhost.
3. `cosyncx engine ping-existing --url http://127.0.0.1:<порт> --config
   <путь-к-config.xml>` проверяет уже работающий экземпляр. Команда
   `status-existing` дополнительно принимает `--folder <ID>` и возвращает
   состояние локальной папки. Эти две команды ничего не меняют в существующем
   Syncthing. API-ключ берётся из локального файла и не выводится в ответе.
4. Команды `engine add-peer` и `engine add-folder` явно добавляют выбранное
   устройство и новую папку через локальный API. Они не заменяют существующие
   устройства и папки и отклоняют пересекающиеся каталоги. Для начального
   источника используйте режим `sendonly`. Эти команды меняют конфигурацию
   выбранного экземпляра, в том числе если он установлен отдельно.

Новый управляемый профиль по умолчанию ограничен loopback, не содержит папок и
не соединяется с другими устройствами. Для передачи требуется явно настроить
прослушивание, устройства и папки на каждом узле. Автоматическая настройка VPS,
автозапуск и интеграция с наблюдателем CoSyncX ещё не готовы.
Оба режима пока проверены только на Linux с временными тестовыми данными;
сборки Windows и macOS необходимо отдельно проверить на этих системах.

Пока реальное автоматическое применение чатов и секретов не проверено. Демо и
тесты должны использовать изолированные временные каталоги и локальные узлы.
