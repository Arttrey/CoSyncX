# Переход на Windows

Эта инструкция подготавливает подключение Windows к существующему VPS. Она не
утверждает, что восстановление чатов на Windows уже проверено.

1. На Windows определите фактические пути к Nexus и профилю Codex; не переносите
   пути с Mac или Linux как готовые настройки. Установите Cursor с расширением
   Codex и запустите или установите Syncthing.
2. Добавьте устройство Windows на VPS и VPS на Windows. Для первоначальной
   загрузки настройте Windows на приём копии Nexus и отдельных папок активных
   историй, названий и связей чатов с VPS. Проверьте режим папок и окончания
   передачи в Syncthing до каких-либо изменений профиля Codex. Архивные чаты в
   текущую настройку не включайте.
3. Настройте клиентское шифрование папок и передайте пароль на Windows отдельно
   безопасным способом. Не публикуйте пароль, ключи, чаты или конфигурацию с
   секретами в GitHub. Режим VPS и корректность расшифровки нужно проверить на
   Windows; одно подключение устройства этого не доказывает.
4. Перед импортом определите соответствия рабочих каталогов и сохраните
   резервную копию состояния Windows. Не заменяйте исторические пути во всех
   сообщениях и не создавайте отсутствующие проекты по догадке.
5. Проверьте импорт сначала на отдельном тестовом профиле, затем — видимость
   полученных чатов и чтение сообщений в установленном Codex. Проверка на Mac
   не подтверждает работу расширения или индексатора на Windows.

На данный момент CoSyncX не поддерживает проверенное автоматическое изменение
профиля Codex в Windows: текущая реализация проверки процессов и блокировок
работает только на macOS и Linux. Не включайте там автоматическое восстановление
до реализации и проверки этого механизма на Windows. Режим отправки с Windows
также нужно включать только после проверки первоначальной копии и разрешения
конфликтов. VPS не требует установки CoSyncX, если на нём работает Syncthing.
